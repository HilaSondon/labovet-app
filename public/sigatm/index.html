GUÍA PASO A PASO

Cómo cargar el archivo en SIGATM

Recorrido para Actas DNSA. Los nombres de algunas opciones cambian según el programa sanitario.

PASO 1

Creá una nueva Acta DNSA

  1. Ingresá a SIGATM y abrí Actas DNSA.
  2. Tocá el botón azul + Nueva Acta.
  3. En Área, elegí el programa correspondiente al análisis.
  4. Seleccioná el Motivo y Submotivo.
  5. Completá Fecha Toma de Muestra. Los campos Usuario GDE y Documento GDE pueden quedar vacíos.
El número de acta y la fecha de alta se asignan automáticamente.
PASO 2

Indicá dónde tomaste las muestras

  1. En Lugar de toma de muestras, elegí normalmente Unidad productiva.
  2. Escribí el RENSPA y tocá la lupa azul.
  3. Si no conocés el RENSPA, usá el segundo botón azul para buscar el establecimiento.
  4. Completá “Otro lugar” solamente si el origen es distinto del sitio donde se tomó la muestra.
Verificá titular y establecimiento antes de continuar.
PASO 3

Elegí especie, matriz y subí el Excel

  1. Tocá Seleccionar Especie, buscá la especie y confirmala.
  2. Elegí la Matriz; para los sangrados suele ser Suero.
  3. Marcá Muestras y submuestras.
  4. En “Subir archivo de muestras”, tocá Buscar y elegí el Excel generado por esta herramienta.
  5. Después tocá Agregar muestras y revisá la grilla.
No cambies los encabezados del Excel. Si aparecen errores en rojo, volvé a esta herramienta y corregí la fila indicada.
PASO 4

Asigná el ensayo solicitado

  1. En Grupo de análisis, elegí el diagnóstico correspondiente.
  2. Marcá la técnica solicitada por el laboratorio o por el programa.
  3. Podés elegir más de una técnica cuando corresponda.
  4. Tocá el botón azul Asignar.
Para Brucelosis bovina, el grupo habitual es Diagnóstico de Brucelosis. Confirmá la técnica con el laboratorio.
PASO 5

Elegí el laboratorio y finalizá

  1. En Laboratorio Destino, seleccioná el laboratorio que recibirá las muestras.
  2. Usá Grabar borrador si todavía necesitás revisar o completar información.
  3. Tocá Finalizar solamente cuando todo esté correcto.
  4. Imprimí el talón y envialo junto con las muestras cuando corresponda.
Finalizar envía el acta al laboratorio. Para corregirla después puede ser necesario rectificarla o rehacerla.
